# Superstore Sales Analysis 📊

## 📌 Project Overview
This project focuses on analyzing Superstore sales data to understand
sales performance, profitability, customer behavior, and business trends.

The project uses MySQL for data cleaning and analysis and Power BI
to create an interactive dashboard that helps transform raw data
into meaningful business insights.
## 🎯 Project Objectives
- Analyze overall sales and profit performance.
- Identify top-performing regions and product categories.
- Understand customer segments and purchasing behavior.
- Analyze sales trends over time.
- Identify opportunities for business improvement.

## 🛠️ Tools & Technologies
- Microsoft Excel
- MySQL
- Power BI
- SQL
## 📂 Project Structure
- Dataset/ – Original Superstore dataset
- SQL/ – SQL queries for data cleaning and analysis
- PowerBI/ – Interactive Power BI dashboard
- Screenshots/ – Dashboard screenshots

## 🔍 Key Analysis
- Sales and profit by region
- Sales trends over time
- Sales by product category and sub-category
- Customer segment analysis
- Shipping mode analysis
- Business performance insights

- 💡 Key Insights
The West region performed strongly in sales and profit.
The Consumer segment contributed the highest sales and profit.
The South region had the lowest sales among the regions.
Profitability varied across regions and product categories.

Note: These findings should be checked against the final dashboard and SQL results before publication.
